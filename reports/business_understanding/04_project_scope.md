# Purpose

The purpose of this document is to define the boundaries of the Retail Sales Performance Analytics project by clearly identifying what is included, what is excluded, and the major deliverables expected from the project.

Defining the project scope at the beginning helps prevent scope creep and ensures that all project activities remain aligned with the business objectives.

---

# Project Description

This project aims to design and develop an end-to-end retail analytics solution using the Olist Brazilian E-commerce Dataset. The solution will transform raw transactional data into meaningful business insights through data preparation, SQL analysis, exploratory data analysis, KPI development, and interactive Power BI dashboards.

The project follows the CRISP-DM methodology and demonstrates the complete lifecycle of a data analytics project from business understanding to executive reporting.

---

# In Scope

The following activities are included within the scope of this project.

## Business Understanding

* Define simulated business objectives.
* Identify simulated stakeholders.
* Document business requirements.
* Define project scope.

---

## Data Understanding

* Explore all available datasets.
* Understand relationships between tables.
* Document data dictionary.
* Create data inventory.

---

## Data Preparation

* Perform data profiling.
* Assess data quality.
* Handle missing values.
* Remove duplicates where appropriate.
* Standardize data formats.
* Prepare analytical datasets.

---

## Data Modeling

* Identify primary and foreign keys.
* Design analytical data model.
* Create star schema.
* Document table relationships.

---

## Data Analysis

* SQL-based business analysis.
* Exploratory Data Analysis (EDA).
* Statistical analysis.
* Feature engineering.
* KPI calculation.

---

## Dashboard Development

* Design dashboard layout.
* Develop interactive Power BI dashboards.
* Build business reports.
* Validate dashboard outputs.

---

## Business Reporting

* Generate analytical insights.
* Prepare executive recommendations.
* Document findings.
* Publish project documentation.

---

# Out of Scope

The following activities are **not included** in this project due to dataset limitations or project objectives.

* Inventory optimization.
* Demand forecasting.
* Profit margin analysis.
* Marketing campaign effectiveness analysis.
* Customer Lifetime Value (CLV) prediction.
* Customer churn prediction.
* Machine Learning model development.
* Real-time streaming analytics.
* Production deployment.
* Cloud infrastructure implementation.
* Automated data ingestion from live systems.
* ERP or CRM system integration.

# Project Assumptions

The following assumptions apply to the project scope.

* The Olist dataset is considered the single source of truth.
* Historical data is sufficient for descriptive analytics.
* All business scenarios are simulated.
* Project outputs are intended for demonstration and learning purposes.

---

# Project Constraints

The project is constrained by the following factors.

* Analysis is limited to available historical data.
* No inventory or cost data is available.
* No marketing campaign data is available.
* No real stakeholder feedback is incorporated.
* The project does not include predictive or prescriptive analytics.
