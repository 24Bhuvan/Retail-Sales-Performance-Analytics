# Purpose

The purpose of this document is to establish a standardized definition for each Key Performance Indicator (KPI) used throughout the project.

Having a centralized KPI dictionary ensures that all business users interpret metrics consistently and that calculations remain standardized across SQL queries, Python scripts, Excel analyses, and Power BI dashboards.

---

# KPI Classification

The KPIs are grouped into the following business domains:

* Sales Performance
* Customer Analytics
* Product Performance
* Seller Performance
* Delivery Performance
* Customer Satisfaction

# KPI Definitions

## KPI-01: Total Sales Revenue

| Attribute           | Description                                      |
| ------------------- | ------------------------------------------------ |
| Business Objective  | Measure total sales generated by the marketplace |
| Definition          | Sum of all successful order payment values       |
| Formula             | `SUM(payment_value)`                             |
| Data Source         | `olist_order_payments_dataset`                   |
| Business Owner      | Sales Manager                                    |
| Reporting Frequency | Monthly                                          |
| Visualization       | KPI Card                                         |

---

## KPI-02: Total Orders

| Attribute           | Description                            |
| ------------------- | -------------------------------------- |
| Business Objective  | Measure marketplace demand             |
| Definition          | Total number of unique customer orders |
| Formula             | `COUNT(DISTINCT order_id)`             |
| Data Source         | `olist_orders_dataset`                 |
| Business Owner      | Sales Manager                          |
| Reporting Frequency | Monthly                                |
| Visualization       | KPI Card                               |

---

## KPI-03: Average Order Value (AOV)

| Attribute           | Description                                         |
| ------------------- | --------------------------------------------------- |
| Business Objective  | Measure average customer spending per order         |
| Definition          | Average revenue generated from each completed order |
| Formula             | `Total Sales Revenue ÷ Total Orders`                |
| Data Source         | Orders + Payments                                   |
| Business Owner      | Sales Manager                                       |
| Reporting Frequency | Monthly                                             |
| Visualization       | KPI Card                                            |

---

## KPI-04: Monthly Sales Growth

| Attribute           | Description                                                                   |
| ------------------- | ----------------------------------------------------------------------------- |
| Business Objective  | Measure sales growth over time                                                |
| Definition          | Percentage change in monthly sales revenue                                    |
| Formula             | `((Current Month Sales − Previous Month Sales) ÷ Previous Month Sales) × 100` |
| Data Source         | Orders + Payments                                                             |

| Reporting Frequency | Monthly                                                                       |
